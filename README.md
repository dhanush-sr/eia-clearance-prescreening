# Environmental Clearance Pre-Screening Service

Mini Project 13 — UE24AM342AA5 ML System Design and AgentOps, PESU.

A multi-agent service that screens a project description against the EIA Notification, 2006 and returns a cited screening opinion (no clearance / Category B to state / Category A to central), escalating to a human when the evidence is insufficient.

**Status:** Evaluation 1 — corpus confirmed, plan drafted. Service not yet implemented.
